Detailed Description

Configuration structure for the Ember simulation.

This structure holds all the parameters needed to initialize and run the fire simulation. The first group of parameters defines the grid dimensions, simulation steps, and scenarios. The second group defines environmental factors such as wind direction, wind strength, base spread, burn rate, and slope scale. The third group defines terrain properties including fuel, moisture, vegetation, and elevation ranges. The fourth group includes ignition points and output settings for exporting simulation data.
