Detailed Description

Represents a view of the simulation grid, providing access to cell states and properties.

This structure holds the width and height of the grid, along with pointers to arrays representing the state, fuel, moisture, vegetation, and elevation of each cell. It allows for efficient access and manipulation of the grid data without copying the underlying data.
